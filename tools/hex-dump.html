Felicita Arc 패킷 덤프

실물 저울의 raw 패킷을 받아 docs/scale-protocol.md의 오프셋 가정을 검증하는 도구입니다. 제품 코드가 아니라 진단용이며, 정식 구현은 frontend/src/ble/에 새로 작성합니다.

1. 환경

Web Bluetooth는 Chrome/Edge에서만 동작하고 보안 컨텍스트가 필요합니다. 파일을 더블클릭해 열었을 때 아래가 빨간색이면, 레포 루트에서 python -m http.server 8080 실행 후 http://localhost:8080/tools/hex-dump.html로 접속하세요.

2. 연결

ffe0 필터로 안 잡히면 전체 스캔을 쓰세요 — 저울이 광고 패킷에 서비스 UUID를 안 실을 수 있습니다. GATT 전체 탐색은 실제 서비스·특성 목록을 찍어 문서의 UUID가 맞는지 확인합니다(체크리스트 2번). 시뮬레이션은 저울 없이 이 페이지 자체가 정상 동작하는지 확인하는 용도입니다.

6. 바이트별 변화 분석 ★핵심

저울에 물을 조금씩 올리면서 보세요. 파란색(변함)으로 바뀌는 인덱스가 무게를 담은 자리입니다. 문서 가정은 index 2 = 부호, index 3~8 = 숫자 6자리입니다. 파란 칸이 여기와 다르면 문서가 틀린 것이고, 그 결과를 docs/scale-protocol.md에 반영해야 합니다.
